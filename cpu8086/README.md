# cpu8086 — 8086 架构子集 CPU 完整设计

基于本仓库 Rust EDA 工具链（`eda-hdl` 前端 / `eda-sim` 仿真 / VCD 波形），
从**门级逻辑电路** → **RTL 数据通路与控制器** → **存储器与 I/O 系统** → **程序仿真运行**
的垂直贯通设计。

> 定位说明：这是 **8086 架构子集核心**（8086-style subset core），采用 8086 的
> 寄存器组、标志位语义与指令风格，Phase 1 使用 16 位定长指令 + 字寻址以聚焦
> 微架构本身；Phase 2/3 路线扩展到字节流 / ModRM / 段寄存器 / 总线接口单元
> / 预取队列 / 中断（见文末路线图）。

## 2. CPU 内部微架构

```
                    cpu8086 执行单元
  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │  ip[5:0] ──▶ (mem_addr mux) ──▶ 取指 mem[ip]        │
  │                 ▲                    │              │
  │            rs_val[5:0]          ir ◀─┘  imm ◀─(第二字)│
  │                 │                │        │         │
  │                 │     ┌──────────┴────────┴───┐     │
  │                 │     │       译码器           │     │
  │                 │     │ op/rd/rs/funct → 控制  │     │
  │                 │     └──────────┬─────────────┘     │
  │                 ▼                ▼                   │
  │  ┌──────────────────┐   ┌────────────────┐           │
  │  │ regfile16 (8x16) │   │    alu16       │           │
  │  │ AX CX DX BX      │   │ ┌────────────┐ │           │
  │  │ SP BP SI DI      │──▶│ │ripple_     │ │ a=rd_val  │
  │  │ 2读1写 case-mux  │   │ │adder16     │ │ b=imm/1/rs│
  │  └──────────────────┘   │ │(16x全加器) │ │           │
  │          ▲              │ └────────────┘ │           │
  │          │ 写回          │ AND/OR/XOR/移位│           │
  │          └──────────────│ Y + CF PF AF   │           │
  │                         │     ZF SF OF   │           │
  │                         └───────┬────────┘           │
  │                                 │                    │
  │  状态机: S_FETCH → S_FIMM → S_EXEC → (S_FETCH|S_HALT) │
  └────────────────────────────────────────────────────┘
```

关键点：

* **标志位来自加法器物理节点**：OF = 两个最高位进位异或（c14⊕cout），
  AF = bit3 进位，CF/SUB 借位 = 内部进位取反 —— 不是软件模拟。
* **取指-执行三级状态机**：单字指令 2 拍（取指/执行），双字指令 3 拍。
* **统一总线**：取指与访存（LD/ST）分时复用同一 64 字 RAM。

## 3. 模块层次（自底向上）

| 层次 | 文件 | 内容 |
|---|---|---|
| L0 门级 | `rtl/primitives.v` | 全加器（xor/and/or 门原语）、D 触发器 |
| L1 算术 | `rtl/ripple_adder16.v` | 16 位行波进位加法器，导出 c3/c14 进位节点 |
| L2 ALU | `rtl/alu16.v` | ADD/SUB/AND/OR/XOR/SHL/SHR/ROL/ROR + 6 标志 |
| L2 寄存器 | `rtl/regfile16.v` | 8×16 位寄存器堆（case 多路器 = 真实结构） |
| L3 控制 | `rtl/cpu8086.v` | 译码器 + 取指-执行状态机 + 写回/跳转/访存 |
| L4 系统 | `rtl/ram64x16.v`, `rtl/sys8086.v` | 64 字 RAM + 输出 I/O 端口 |
| 验证 | `tb/`, `verify/`, `crates/eda-tests/src/cpu8086_cases.rs` | 单元向量 + 整机程序 + 波形 |

## 4. 指令集子集（16 位定长）

编码：`[15:12] op | [11:9] rd | [8:6] rs | [5:0] funct`

| op | 助记符 | 语义 | 标志 |
|---:|---|---|---|
| 0 | `MOV rd, rs` | rd ← rs | 不变 |
| 1 | `MVI rd, imm16` | rd ← 第二字 | 不变 |
| 2 | `ADD rd, rs` | rd ← rd+rs | 全部 |
| 3 | `SUB rd, rs` | rd ← rd−rs | 全部 |
| 4/5/6 | `AND/OR/XOR` | 位逻辑 | CF=OF=0 |
| 7/8 | `INC/DEC rd` | ±1 | 除 CF |
| 9 | `CMP rd, rs` | rd−rs 丢弃 | 全部 |
| A | `SHL/SHR/ROL/ROR` | funct 选择 | CF/OF/ZF/SF |
| B | `JMP addr16` | IP ← 第二字 | 不变 |
| C | `JZ/JNZ/JC/JNC/JS/JNS addr16` | 条件跳转 | 不变 |
| D | `OUT port, rd` | 端口 ← rd | 不变 |
| E | `HLT` | 停机 | 不变 |
| F | `LD rd,[rs] / ST [rs],rd` | funct=0/1 | 不变 |

寄存器：`0=AX 1=CX 2=DX 3=BX 4=SP 5=BP 6=SI 7=DI`（8086 EU 通用组），
另有 IP、IR、IMM、FLAGS{CF,PF,AF,ZF,SF,OF}。

## 5. 演示程序（机器码见 `programs/prog1.md`）

1. **算术**：`MVI AX,5; MVI BX,3; ADD AX,BX; OUT AX; HLT` → io_out=8
2. **循环**：累加 3+2+1，`DEC`+`JNZ` 回跳 → io_out=6
3. **访存**：`ST [SI],AX` 后清零再 `LD` 读回 → io_out=0x1234
4. **溢出**：`MVI AX,0x7FFF; INC AX` → OF=1, SF=1, CF 保持 0

## 6. 验证层次

1. **门级交叉验证**：ripple_adder16 vs 行为级 `a+b`，含 c3/c14 进位节点
2. **ALU 全标志向量**：进位/借位/溢出/奇偶/半进位/移位回绕逐项检查
3. **整机程序仿真**：4 个机器码程序跑真状态机，检查 io_out、内部寄存器、
   RAM 单元、标志位（经层次化网名 `u_cpu.u_regs.r0` 等直接观测）
4. **波形**：VCD 导出含全部层次信号

SUITE_FILTER=cpu8086 cargo test -p eda-tests --test suite

## 7. 完整 8086 演进路线（Phase 2/3）

| 阶段 | 内容 |
|---|---|
| P2a | 字节流取指 + 变长指令 + ModRM 译码（真实 8086 操作码） |
| P2b | 段寄存器 CS/DS/SS/ES + 20 位物理地址 `seg<<4 + off`（1MB 空间） |
| P2c | 总线接口单元 BIU + 6 字节预取队列（EU/BIU 分离，真实 8086 结构） |
| P3 | CALL/RET/PUSH/POP（栈）、字符串指令、中断与 INTR/NMI、最小/最大模式 |
