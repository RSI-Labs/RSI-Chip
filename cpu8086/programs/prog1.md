# cpu8086 演示程序集（机器码级）

指令格式：`[15:12]=op [11:9]=rd [8:6]=rs [5:0]=funct`，双字指令的第二字为
立即数/跳转目标。寄存器：`0=AX 1=CX 2=DX 3=BX 4=SP 5=BP 6=SI 7=DI`。

## 程序 1 — 算术与输出（`tb_sys_program1.v`）

| 地址 | 机器码 | 汇编         | 说明 |
|-----:|-------:|--------------|------|
| 0 | `1000` | `MVI AX, 5`  | op=1 rd=AX |
| 1 | `0005` |              | 立即数 |
| 2 | `1600` | `MVI BX, 3`  | op=1 rd=BX |
| 3 | `0003` |              | 立即数 |
| 4 | `20C0` | `ADD AX, BX` | op=2 rd=AX rs=BX |
| 5 | `D000` | `OUT 0, AX`  | op=D funct=port0 |
| 6 | `E000` | `HLT`        | |

预期：`io_out=0008`，`AX=8`，`ZF=0 SF=0 CF=0 OF=0 PF=0 AF=0`。

## 程序 2 — 循环与条件跳转

| 地址 | 机器码 | 汇编 | 说明 |
|-----:|-------:|------|------|
| 0 | `1200` | `MVI CX, 3` | 计数器 |
| 1 | `0003` | | |
| 2 | `1000` | `MVI AX, 0` | 累加器清零 |
| 3 | `0000` | | |
| 4 | `2040` | `ADD AX, CX` | loop: 累加 |
| 5 | `8200` | `DEC CX` | 计数递减（不影响 CF） |
| 6 | `C001` | `JNZ loop` | funct=1 → JNZ |
| 7 | `0004` | | 目标地址 4 |
| 8 | `D000` | `OUT 0, AX` | 输出结果 |
| 9 | `E000` | `HLT` | |

预期：`io_out=0006`（3+2+1=6）。

## 程序 3 — 存储器读写（LD/ST）

| 地址 | 机器码 | 汇编 | 说明 |
|-----:|-------:|------|------|
| 0 | `1C00` | `MVI SI, 10` | 数据地址 |
| 1 | `000A` | | |
| 2 | `1000` | `MVI AX, 1234h` | |
| 3 | `1234` | | |
| 4 | `F181` | `ST AX, [SI]` | funct=1、rs=SI → 存储到 mem[10] |
| 5 | `1000` | `MVI AX, 0` | 破坏原值 |
| 6 | `0000` | | |
| 7 | `F180` | `LD AX, [SI]` | funct=0、rs=SI → 从 mem[10] 读回 |
| 8 | `D000` | `OUT 0, AX` | |
| 9 | `E000` | `HLT` | |

预期：`io_out=1234`，`mem[10]=1234`，`AX=1234`。

## 程序 4 — 有符号溢出（INC）

| 地址 | 机器码 | 汇编 | 说明 |
|-----:|-------:|------|------|
| 0 | `1000` | `MVI AX, 7FFFh` | 最大正数 |
| 1 | `7FFF` | | |
| 2 | `7000` | `INC AX` | 溢出到负数 |
| 3 | `D000` | `OUT 0, AX` | |
| 4 | `E000` | `HLT` | |

预期：`io_out=8000`，`OF=1`（正+1→负），`SF=1`，`CF=0`（INC 不影响 CF）。
